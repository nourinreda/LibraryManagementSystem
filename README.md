\# Library Management System



A console-based Library Management System built with \*\*C# and .NET 10\*\* to practice Object-Oriented Programming and data persistence.



\## Features



\* Manage books, magazines, and reference books

\* Manage library members

\* Track total and available copies

\* Borrow and return library items

\* Track loans and due dates

\* Calculate overdue fines

\* Save and load library data using JSON

\* Polymorphic JSON serialization and deserialization



\## Concepts Practiced



\* Object-Oriented Programming (OOP)

\* Encapsulation

\* Inheritance

\* Abstraction

\* Interfaces

\* Polymorphism

\* Collections

\* LINQ

\* Exception Handling

\* File Handling

\* JSON Serialization / Deserialization
